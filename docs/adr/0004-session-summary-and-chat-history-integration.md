# ADR 0004: Робоча сесія, рефакторинг та інтеграція історії чату у RAG

## Статус
Прийнято (Accepted)

## Контекст
У ході інтенсивної розробки проєкту `apple-silicon-local-ai` було внесено значні архітектурні покращення:
1. **Чистка та рефакторинг**: Перенесення CLI-чату в папку `cli-chat/`, видалення тимчасових тестових серверів.
2. **Детерміновані `point_id` та метадані Git**: Впровадження хешування `hash(file_path:chunk_index)` у Rust RAG для запобігання дублікатам та додавання `git_repo` / `project_name` payload полів.
3. **Гібридна AI-Архітектура**: Визначення моделі "Senior Architect (Cloud) + Middle Developer (Local Devstral-24B)".
4. **Скіли та Документація**: Публікація `README.md` (UA/EN), запуск скілів у `.agents/skills/` (`codebase-indexer`, `local-code-reviewer`).
5. **Ізольована індексація чатів**: Створення колекції `chat_history` у Qdrant та додавання інструменту `qdrant_index_chat_history`.

## Рішення
- Зберігати архітектурні рішення у вигляді ADR-документів у `docs/adr/` ( Knowledge Extraction Pattern ) та індексувати їх у `codebase_knowledge`.
- Зберігати сирі транскрипти чатів у суворо відокремленій колекції `chat_history`, яка не змішується з RAG вихідного коду.

## Наслідки
- **0.00$ витрат на рутину**: Масові запити, самаризація та векторизація обробляються локально на Apple Silicon.
- **Чистота векторного пошуку**: Кодова база не забруднюється розмовним шумом.
